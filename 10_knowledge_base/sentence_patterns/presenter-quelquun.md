---
Pattern: 介紹別人（職業 + 國籍）
Structure: "C'est + un/une + [職業名詞] + [國籍形容詞]."
Meaning: 指著／提到某人，說明他的職業和國籍
Examples:
  - "C'est un acteur américain."
  - "C'est un chanteur américain."
  - "C'est une chanteuse française."
  - "C'est une sportive japonaise."
Common Mistakes: 冠詞、職業名詞、國籍形容詞三者的陰陽性必須一致（❌ C'est un sportive → ✅ C'est un sportif / C'est une sportive）；國籍形容詞放在名詞**後面**，跟英文相反（❌ un américain acteur）
Source: 課本 Unité 1 p.19；Lesson 04（2026-08-01）筆記 p.10

- 三個位置要同時對齊性別，錯一個就整句不對：
  | | 陽性 | 陰性 |
  |---|---|---|
  | 冠詞 | un | une |
  | 職業 | chanteur / acteur / sportif | chanteuse / actrice / sportive |
  | 國籍 | américain | américaine |
- **形容詞後置**是法語跟中英文最直覺衝突的地方：un acteur **américain**（一個演員，美國的）
- 跟 [[se-presenter]] 的差別：那邊是講自己（Je suis...），這邊是講第三者（C'est...）
- ⚠️ 用 **être** 講職業時不加冠詞（Je suis chanteuse.），用 **c'est** 時要加（C'est une chanteuse.）——兩種說法都對，但冠詞規則不同，見 [[articles-indefinis]]
