Topic: 不定冠詞 un / une / des（以及跟定冠詞的分工）
Level: A1
Rule: 陽性單數 = un；陰性單數 = une；複數（不分陰陽性）= des。用在「不特定、第一次提到、隨便一個」的名詞前；相對地 le/la/l'/les 用在「特定、雙方都知道是哪一個、或泛指整個類別」
Examples:
  - "un jour（某一天）／une semaine（一個星期）／un mois／une année"
  - "un chanteur（一個歌手，不知道是誰）↔ le chanteur（那個歌手）"
  - "C'est un acteur américain.（介紹別人，第一次提到 → un）"
  - "La fête nationale, c'est le 14 juillet.（一年只有一個 → le）"
Exceptions: 職業/國籍當表語時，être 後面不加冠詞（Je suis chanteuse.），但 c'est 後面要加（C'est une chanteuse.）

- 課堂上的一句話總結：**un/une = 不特定，le/la/les = 特定**
- 判斷流程：先問「聽的人知道我在講哪一個嗎？」
  - 不知道／第一次提到 → un / une / des
  - 知道，或世界上就這一個 → le / la / l' / les
- **日期是這條規則最好的例子**（見 [[dire-la-date]]）：
  - *le* 14 juillet — 一年只有一個 14 juillet，是 **date précise** → 定冠詞
  - C'est samedi — 星期六每週都有很多個，不特定 → **不加冠詞**
- 定冠詞還有一個不定冠詞沒有的用法：**泛指整個類別**（J'aime le cinéma = 我喜歡電影這件事），見 [[articles-definis]]
- des 在本課筆記裡還沒正式出現，先記著陽性/陰性單數兩個就好
