---
Topic: 國籍形容詞的陰陽性變化（adjectifs de nationalité）
Level: A1
Rule: 陽性形容詞 + e = 陰性（一般規則）；陽性字尾為 -ien / -éen → 陰性 -ienne / -éenne（加雙 n 再加 e）；陽性字尾已經是 -e → 陰陽性同形不變；少數特例字尾 -c → -que
Examples:
  - "français → française（一般規則）"
  - "chinois → chinoise、américain → américaine、allemand → allemande、espagnol → espagnole"
  - "italien → italienne（-ien 規則）、coréen → coréenne（-éen 規則）"
  - "belge、russe、tchèque：陽性已 -e 結尾，陰陽性同形不變"
  - "grec → grecque、turc → turque（特例 -c → -que）"
Exceptions: grec/turc 這組 -c 結尾不套用「加 e」規則，要背成特例；已 -e 結尾的同形形容詞要靠 un homme / une femme 才分得出性別
Related: "[[etre]]"
Source: 課本 p.19 Grammaire「Les adjectifs de nationalité」，Lesson 03（2026-07-25）；Lesson 04（2026-08-01）大量練習補齊例字表與同形判斷法；Lesson 05（2026-08-08）補三個新字（argentin/vietnamien/suédois）+ 課本 p.22 陰陽性發音辨識練習

- 判斷流程：先看陽性字尾 → 屬於 -ien/-éen 就加雙 n 再加 e；屬於已經 -e 結尾就不變；屬於 -c 特例就查記憶清單；其餘一律直接加 e
- 常見混淆：taïwanais 屬於**一般規則**（加 e → taïwanaise），跟 -ien 那組（italien→italienne）不是同一套規則，容易搞混（見 evidence_log 2026-07-25：fanancais/taïwanaise 拼字嘗試）
- 國籍形容詞**小寫**（不像英文 French 大寫）：je suis française，不是 Française

| hollandais | hollandaise | /ɔ.lɑ̃.dɛ/ → /ɔ.lɑ̃.dɛz/ |
| chinois | chinoise | /ʃi.nwa/ → /ʃi.nwaz/ |
| américain | américaine | /a.me.ʁi.kɛ̃/ → /a.me.ʁi.kɛn/ |
| marocain | marocaine | /ma.ʁɔ.kɛ̃/ → /ma.ʁɔ.kɛn/ |
| allemand | allemande | /al.mɑ̃/ → /al.mɑ̃d/ |
| espagnol | espagnole | /ɛs.pa.ɲɔl/ → /ɛs.pa.ɲɔl/（同音）|

|---|---|---|
| italien | italienne | /i.ta.ljɛ̃/ → /i.ta.ljɛn/ |
| colombien | colombienne | /kɔ.lɔ̃.bjɛ̃/ → /kɔ.lɔ̃.bjɛn/ |
| tunisien | tunisienne | /ty.ni.zjɛ̃/ → /ty.ni.zjɛn/ |
| coréen | coréenne | /kɔ.ʁe.ɛ̃/ → /kɔ.ʁe.ɛn/ |
| vietnamien | vietnamienne | /vjɛt.na.mjɛ̃/ → /vjɛt.na.mjɛn/ |

### 規則三：已 -e 結尾 → 陰陽性同形

belge /bɛlʒ/・russe /ʁys/・suisse /sɥis/・tchèque /tʃɛk/（捷克）

⚠️ **同形就分不出性別**——這時候要**靠加上名詞**：
- **un homme** belge（比利時男人）／**une femme** belge（比利時女人）
- 練習題問「H 還是 F」時，答案只能從題目給的 un/une 或 homme/femme 判斷，形容詞本身給不了線索

### 規則四：-c → -que（特例，拼字變、發音不變）

| 陽性 | 陰性 | IPA |
|---|---|---|
| grec | grecque | /ɡʁɛk/（兩者同音）|
| turc | turque | /tyʁk/（兩者同音）|

- 這組只有**寫**的時候看得出陰陽性，**聽**是聽不出來的

### 課本 p.22：陰陽性發音辨識練習（Lesson 05，2026-08-08）

- 練習形式：「Écoutez les adjectifs. La prononciation est identique ou différente ?」——聽陽性/陰性形容詞，判斷發音相同還是不同
- 正是規則三（-e 結尾同形，發音也相同）跟規則四（-c→-que，拼字變但發音不變）的聽力驗證版：這兩組**聽起來都一樣**，規則一、二（一般 +e、-ien/-ienne）**聽起來會不一樣**（陰性多一個子音尾音）
